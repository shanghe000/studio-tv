# 资产库交互整理（2026-10-08）

## 对照与边界

对照了 RunningHub 当前资产库：个人/团队范围、目录内容、新建文件夹和批量管理属于同一个资产工作区。原站当前登录账户的团队页显示“请先切换到团队账号”，因此未将其团队成员流程视为已验证参照。STUDIO 的组织规则仍为内部团队和成员共享；IPAC 只控制产品准入。

保持现有中性深色、字号、输入框、卡片和弹窗风格，不修改冻结原生资源、后端权限或接口契约。

## 层级与导航

- 资产库 → 个人资产 / 团队资产 → 选择团队 → 文件夹 / 子文件夹。
- 团队管理是当前资产位置上的弹窗；可打开团队资产、查看成员或创建团队。团队名称和删除操作收进更多菜单。
- 成员列表 → 添加成员，或成员权限 → 移除确认。一次只存在一个弹窗，不堆叠多层可操作背景。
- 目录工具区只放新建文件夹和发布；文件夹整卡可点击，路径面包屑和上一级按钮提供明确返回路径。
- 发布：明确目标团队与目录 → 切换个人素材/已存节点 → 搜索、预览、选择 → 可选改名 → 发布。不会预选第一个来源。
- 导入：明确选择可编辑项目 → 导入成功 → 留在资产库或打开项目。只读项目不出现在目标列表。

团队对话框步骤写入原生路由的 URL 与历史 state。Back/Cancel/Escape 返回一层，Forward 恢复相应步骤而不提交；刷新保留弹窗祖先记录。移除成员成功跳过失效的成员编辑步骤，回到成员列表。直接打开弹窗深链接时，关闭回到该团队和目录，不跳出站点。切换对话框不重挂或请求背后的目录列表。

个人资产库通过现有组件公开回调同步两级文件夹路径及创建弹窗到 URL，支持刷新、前进和后退。找不到的目录回到有效父级并提示。原生资源保持冻结。团队选择与登录身份分开，切换团队资产不会再把个人头像变成 TEAM。

## 表单与请求

新增成员先搜索并明确选人，再选择权限；Enter 在搜索框中只搜索，默认只读，已加入成员不可重复选择。删除与移除使用独立确认。表单保留校验和失败输入；提交期间禁用操作并合并重复提交；写入保持原有身份校验、幂等键和展示版本的 If-Match。关闭/换号后的迟到结果不会回写界面。

发布来源和可编辑项目按接口分页完整读取；异常分页明确报错，不静默截断。关闭发布弹窗后不再继续请求后续页。只读成员不会出现写入控件，直接访问写入弹窗 URL 同样被拒绝，后端鉴权继续生效。
