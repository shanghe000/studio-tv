# Studio TV 品牌

网站名称为 Studio TV。品牌改动放在 `apps/web/src/brand` 和 `apps/web/public/brand`，原生组件和编译资源保持冻结，项目、素材、登录与后端协议不变。工程与部署名称为 `studio-tv`；既有存储和登录协议标识保留兼容。

电视标志由圆角屏幕、天线和一个播放三角组成；不增加复杂装饰。首页、画布返回按钮、Agent 模式小图标、插件品牌和网站图标使用同一方向。

图形外观和动画直接移植自用户指定的 [导演工作台](http://192.0.2.10:8781/director/?screen=home&pid=2cada6d7-76b0-48b1-8c55-97513e4990a9)，固定采用“焰橙”配色。SVG 路径与渐变、4.8 秒浮动/呼吸/阴影、6 秒摆尾、6.7 秒双眨眼、目光跟随、点击跳跃/火花和 35 秒闲置休息沿用参考参数，并遵循 reduced-motion。保留本项目原生拖动、边界限制、位置存储和助手切换，不删除 React 管理的节点。网站紫色主题和其他图标不改动。

参考资源为 `/assets/director-CH_m1VmO.js` 和 `/assets/director-DajG297X.css`。仅迁移图形表现层，不迁移参考站聊天内容、配色面板或位置避障逻辑。

按用户要求，图形不显示名字、交互提示或睡眠字母（“小焰”“休息一下”“点击聊创作”“z”）。休息仍通过闭眼、头部倾斜和慢摆尾表达；焰橙外观、其他动画和原生交互保持原样。

图形迁移验收：6 条 SVG 路径与参考逐项相同，保留的 9 组动画关键帧相同（睡眠字母动效随文字移除）；浏览器验证焰橙配色、悬停腮红、12 个点击火花、拖动姿态与原位置恢复、目光跟随、助手开关后的动画暂停/恢复、35 秒闲置休息/指针唤醒、减少动态效果，以及页面缓存生命周期事件清理/重装均通过。减少动态效果的浏览器模拟已恢复。

颜色覆盖读取同源样式中的旧品牌荧光绿声明，保留透明度、媒体查询及 CSS 层；原样式文件不改写。不会对页面整体或用户图片应用颜色滤镜。用户项目名、富文本和素材文件名不改写；模型目录中的第三方供应商名称保留。插件说明的品牌文案更新不表示后端或下载的第三方插件已经服务化。

HTML、网站图标与未带内容哈希的品牌素材使用 `Cache-Control: no-cache`，发布后重新验证；API 和存储请求的缓存规则不变。

创作模块展示名统一为 Studio Frames。入口、弹层和嵌入编辑器使用同一简约焰橙图形；原 SVG、按钮与事件保留，仅覆盖图形和静态品牌文案。入口提供轻量悬停动效和 reduced-motion。底层 HyperFrames 路径、协议及作品内容保持兼容；不替换用户标题、聊天、生成预览或自定义说明。

内部模式隐藏生成积分、模型单价及计费提示，覆盖主页、画布、优化弹窗、分镜批量动作和嵌入编辑器。取消提示仅移除已知费用句，保留动作按钮与正常说明；上下文和 token 用量信息保留。

验收：TypeScript 检查、22 项前端测试、生产构建及 1198 项原生资源 SHA 校验通过。浏览器核对首页/插件页标题和字标、画布电视按钮与图形、旧品牌绿的颜色覆盖、助手开关及拖动；小屏显示按原有响应布局处理。真实飞书登录尚待上一阶段的 IPAC 认证来源修正，这轮未修改认证或数据库。
