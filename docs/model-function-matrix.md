**不同按钮不等于不同模型。** 分镜大师 45 个叶功能复用 G2 优先路由，以不同 `sceneCode` 分流；人物调节复用 P5，传 `presetSelections/promptCodes`。本轮实际读取的 162 个人物预设全部 `promptHidden=true`，前后缀正文均为 null。能证明“隐藏预设被引用”，不能证明后台仅替换了 `system` 提示词，也不能还原预设正文。姿态/自定义妆容还会增加参考图条件。人物“实时预览”是本地叠图/骨架，真正调用模型的是人物面板底部生成按钮。

三视图是图像生成布局能力，不是 3D 几何生成；全景图需要全景图像输出，WebGL 预览另属本地；2D画板把绘制层合成为 1024×1024 PNG，再传 `prompt/image/styleCode/generationMode`，因此至少是草图条件图像生成。它没有暴露 `modelCode`，`styleCode` 是否只改提示词、是否切模型/工作流仍未知。

表中“提示词编排”指前端明文拼接已可见；“隐藏场景预设”指场景/预设标识分流；“模型/能力切换”指目录路由或输入输出条件不同，**不等于已证实更换权重**；“多阶段编排”含模型、工具和媒体处理组合；“待确认”单列没有足够执行证据的入口。枚举选项不是独立模型，人物162预设完整名称/编码放在配套 JSON。

本表有 **207 条模型相关功能或待核对入口 + 7 条非模型边界说明**。坐标包含复用入口与单/批量操作，不能当作独立模型数量。完整原始坐标、参数证据、162预设和42类目录的302条路由记录见 [model-function-matrix.json](model-function-matrix.json)。未返回配置的类型/仅有包装器的功能会注明，未将翻译词条当成已挂载按钮。

公共请求记为 **G**：`POST /canvas/task/run {canvasId,targetType:"NODE"或"GROUP",targetId,canvas:{nodes,edges}}`，模型字段在目标节点 `data.modelCode/subType/toolsType/sceneCode/params`。字段是目录/源码示例，精确名称、必填、范围、参考数量、输出数量以选定模型 `config` 为准，不统一硬编码。例：相同名称的不同 `modelCode` 不能证明共用权重。

路由简称：**G2**=`image-imagerhart-image-g-2-official-image-to-image`；**P5**=`seedream-v5-pro-image-to-image`；**PAN**=`image-image-rhart-image-n-g31-flash-official`。`ix/ed/sk/dr/oc/hf@N` 是本轮捕获 JS 的0起始字符位置；机器文件存了源文件哈希与具体偏移。
