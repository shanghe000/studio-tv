## 官方视频报价

费用位于参数区、生成按钮上方，随规格及实际参考素材更新，展开后可查看公式、公开价核对日期与官方来源。MiniMax 按个人凭据地区显示 USD 或 CNY；无 Key 时明确显示地区未确认。自部署不显示厂商 API 费用。

真实网页检查：MiniMax 国际 H3 768P、5秒为 US$0.40，2K、10秒为 US$1.30；同一2K规格切换中国大陆地区为¥8.00。Seedance 2.0 720P、16:9、5秒为¥4.968，4:3、5秒为¥4.999309；连续切换时长后没有旧报价覆盖新报价。自动规格显示范围；含6秒视频参考的480P、5秒案例显示¥3.093552起。素材不兼容时显示费用未知，不能视为免费。

Seedance 的输入视频最低计费 token 完整表尚未核实，因此含视频参考的金额是已知基础公式的起价，没有承诺上限。没有查询余额、发起收费任务或以这些数字充当真实账单。官方来源与算法见 `docs/model-price-estimates.md` 及 Router `docs/video-price-estimates.md`。

原生节点本身提示窗口衔接仍可产生动作变化，并建议参考图由源视频同姿态、同构图的画面重绘。本例参考图与源视频背景不同。网页因此补充具体选图建议和长片手势/背景限制；保持 MANUAL_TEST，不以这一个案例提升其他11个规格或其他动作工作流。没有通过重跑随机种子掩盖首次结果。

H3 新参数版接受2～30秒源视频，时长随源视频。旧 H3 节点保留历史规格；Wan Animate2、SCAIL2 目前仍只使用前约5秒，网页明确显示其5.2～15秒源素材限制，未宣称本轮完成这些模型或多人替换的真实视频验证。
