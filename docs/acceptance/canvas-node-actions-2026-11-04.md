# 画布节点工具：入口、参数和验收口径（2026-11-04）

本表按固定网页版本的图片、视频可配置工具栏注册项计数，固定附加按钮、子菜单和快捷入口另列，避免重复。测试逐一读取实际网页注册表中的工具 ID，与产品可用性规则对照；工具栏按钮和“更多”菜单使用相同规则。灰色控件保留焦点、悬停原因，鼠标和键盘均不能触发原命令。账号可用模型来自 STUDIO 目录，不计占位模型或测试模型。

| 工具栏 / 数量 | 实际入口 | 执行条件及结果 |
|---|---|---|
| 图片 / 1 | 解析 | 需要可用的图片理解模型，输出文本。 |
| 图片 / 5 | 人物调整、分镜、3D 视角、打光、去文字 | 单张当前选中图片，参考编辑模型。分镜预设由服务生成指令；普通图像编辑仍须填写描述。 |
| 图片 / 2 | 全景、画质 | 全景查看使用现有内容；生成全景需要参考编辑模型。画质中的生成式修复用参考编辑模型，高清 / 放大使用专门的 SeedVR2，图片尺寸不合规则时不能提交。 |
| 图片 / 5 | 宫格裁剪、图片编辑、调节、裁剪、旋转 | 原生图像处理、预览或上传处理结果，不要求推理模型。 |
| 图片 / 4 | 重绘、擦除、扩图、抠图 | 专门的区域工具要求 Codex 参考编辑 v3。重绘传蒙版引导和局部描述，擦除 / 扩图传相应引导，抠图使用原图并明确请求透明输出。其他通用参考编辑型号不冒充这些能力。 |
| 图片 / 1 | 编辑元素（图片分层） | 当前目录无分层模型，置灰。 |
| 视频 / 4 | 裁剪、倍速、倒放、旋转 / 镜像 | FFmpeg 媒体任务；按源素材、裁剪区、倍速及旋转 / 镜像参数提交。倍速预设、滑块和目标时长按相同的 0.25～4 倍限制，含边界。 |
| 视频 / 3 | 编辑、捕捉帧、音频分离 | 编辑打开操作面板，并不代表面板中所有渲染方式开放。捕捉帧是素材处理；音频分离菜单仅开放提取完整音轨，人声 / 环境音分离仍灰。 |
| 视频 / 5 | 片段重拍、专门的画质处理、深度捕捉、视频解析、视频修复 | 未接通对应服务，置灰。 |

合计图片 18 项、视频 12 项。11 月 4 日目录在有合规素材时，30 个主入口中有 24 个可触发操作或打开含可用功能的菜单，6 个因无服务而置灰。这是**入口计数**，不等于 24 个模型，更不能把打开菜单算作已经生成成片。

其他入口：固定的“一键复刻”、视频草案渲染、AI 应用、音频转文案、图片对口型、导演台 AI 场景识别均在执行前拦截。导演台手动布景和截图保留。文本选区 / 添加节点 / 右键下游的文生视频要求账号拥有可用的文生视频版本；已有图片 / 视频可按具体型号的输入要求生成。音频节点的“音频生视频”会创建视频节点并保留音频连线；账号配置了支持单音频参考的官方 MiniMax H3 或 Seedance 2.5 全能参考型号时可用，要求视觉参考的型号不计入。已有媒体可继续播放或使用本地工具；未接入的音乐、语音和 3D 生成不会因媒体可播放而开放。视频 FFmpeg 结果不能从模型“重试”入口重新提交；回到源视频可重新处理。

## 怎么复验

- `tests/web/node-tool-contract.test.ts`：从冻结网页注册表取得 18 + 12 个实际键，检测“更多”入口全部覆盖；再验证选区回调、账号目录变化、缺少专门模型、无节点上下文的菜单、来源历史和非法倍速。
- `tests/web/image-subfeature-comfy-contract.test.ts`、`tests/web/image-semantic-tools.test.ts`：通过真实 STUDIO 前端适配器导出 63 种生成请求：Qwen 45 个原生快捷分镜/灯光/视角等预设、6 个编辑场景名和 1 个已登记人物预设；Codex 9 个编辑/人物/全景/区域工具；SeedVR2 2 个放大入口。45 个预设执行冻结网页里的命令构造器，其他参数样例使用工具的命令形态；不能将 63 个请求表述成 63 次浏览器点击。可用 `STUDIO_CANVAS_ACTIONS_EXPORT=/path/to/new.jsonl npm run test:web -- tests/web/image-subfeature-comfy-contract.test.ts tests/web/image-semantic-tools.test.ts` 从头生成供 STUDIO 服务 / Router 边界测试使用的 JSONL；输出文件须为空或尚不存在。
- `tests/web/native-media-actions-boundary.test.ts`：用冻结网页的媒体处理命令生成器跑到 STUDIO 的独立媒体接口，含裁剪、两端倍速、倒放、左右旋转、水平 / 垂直镜像、旋转加镜像，共 9 条实际提交体。FFmpeg 不走模型 Router，不应计入模型生成次数。
- `tests/web/native-audio-video-shortcut.test.ts`：验证音频节点快捷入口，执行冻结网页建点与连线逻辑，再选型号，单音频提交。5 条官方型号均检查 `REFERENCE_AUDIO` 绑定；其他型号或账号无 Key 不开放。
- 真实浏览器在隔离画布验证视频菜单灰显、人声分离点击后不创建节点、捕捉帧可打开；图片“剧情推演四宫格”可从上传图新建结果并发出画布运行请求。这一步截在测试服务边界，没有生成线上图片 / 视频。[视频工具栏实图](../../apps/web/public/guide/images/canvas-tool-availability-20261104.png.svg)。
- 单独的浏览器本地裁剪、播放、保存、导出等操作按其本地交互与文件结果检查，不适用“到达模型 Router”指标；本次实点与自动化边界见上，不据此声称所有本地按钮均重新实点或所有模型已出片。

## 实际运行结果

上述 63 项图片生成和 5 项单音频参考请求均已通过隔离 STUDIO HTTP 服务并到达有签名的模型调用边界，没有触发真实推理。

媒体不用模型：9 个视频处理和 1 个换线后重新提取完整音轨的请求均经 STUDIO 媒体接口、SQL 队列、本机 FFmpeg、资产导入、下载并完整解码。输入为随时间改变、左右不对称、带声道的 6 秒影片。除尺寸、时长和编码外，逐个对比 9 个输出在第 0.75 秒的画面像素，验证裁剪内容、镜像/旋转方向、倒放和速度；提取的 PCM 音轨验证为有声、时长 6 秒。见[十个输出的测量结果](canvas-media-outputs.csv)。

复验命令：`python3 scripts/test-canvas-media-boundary.py --out <新目录>`。事先设置指向可创建临时数据库的 `TEST_DATABASE_URL`；FFmpeg 和 FFprobe 可在 PATH 中，或分别通过 `TEST_FFMPEG_PATH`、`STUDIO_TEST_FFPROBE` 指定。脚本只使用新建的本机监听器、测试用户和合成素材。

## 各节点的独立操作

下表涵盖端口注册表的 17 类基础节点，另列分组。单个节点能作为上游素材、能进入编辑器、能提交模型、能产出文件是不同的检查。旧功能编号对应[功能台账](../canvas-node-status.md)。表中的“接线”表示核对了原生控件和接收代码，实测范围单列。

| 节点 | 可使用的功能与条件 | 灰色项及本地操作 | 本次证据与范围 |
|---|---|---|---|
| 图片、视频（2 类） | 图片编辑与视频生成按真实型号、版本及当前连线校验。已有结果可打开工具。 | 图片分层与不支持的视频分析、修复等见上方 30 项工具表。播放、预览无需生成。 | 63 条图片工具模型请求，10 项真实媒体输出。视频模型另见型号矩阵。 |

### 人物、角色设计和服装的来源

图片面板的系统目录和 STUDIO 编译器共用 189 条预设定义。9 条为滤镜、功能与相机，18 条为角色设计（其中 3 条穿搭），162 条为人物外观、表情等。前端索引只保留键名和 ID，`image-preset-readiness` 测试逐项比对目录；Go 的 `TestImageRecipesFreezePublishedAndStudioRoleDefinitionsAsUserConditions` 对 189 条逐个编译并核对条件。原生服装子分类沿用对应的 clothing 预设。旧节点保存了已取消的 STUDIO 系统标识时，生成按钮会提示第几项须重选。历史选项只带 STUDIO promptCode 时，服务按该项的完整键名和已登记代码解析。

分镜实体面板的“生成服装”使用当前项目可选择的实体 ID。原生 `DNr` 在候选变化时移除已消失的选择，只读、处理中或没有选择时禁用提交。它没有固定的公开服装款式数量；所选实体作为图像参考进入后续处理，验证范围见 S05。
