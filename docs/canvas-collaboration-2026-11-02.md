# 多人画布协作与节点短时占用

2026-11-02。传输与权限细节见 [IMPLEMENTED 扩展合同](../contracts/canvas-presence-extension.md)。沿用现有画布保存、版本 CAS、事件订阅和三方合并；没有更改冻结原生编辑器资源，也没有把本地 Yjs 文档直接联网。

新增的独立 `/presence/events` 使用鉴权 fetch SSE 推送光标、在线成员与节点占用，指针更新合并为最多约每110ms一次POST。SSE配额或传输不支持时以1秒JSON轮询恢复，认证或项目权限失败不会降级绕过。光标不进入画布、历史或持久日志。当前在线状态在单API实例内广播；多实例部署需要共享广播层。节点租约使用PostgreSQL，跨实例互斥不依赖进程内状态。

租约15秒到期，页面5秒续期。验证身份、登录会话与随机页面ID共同确定所有者，客户端不提供可信姓名或角色。节点抢占、快照保存、画布命令和交互生成提交在同一项目行锁下检查；仅伪造页面ID不能续用别人的租约。缺少页面头的旧客户端也不能覆盖被占用节点。已有幂等提交可以重放，可信后台任务回写沿用输入绑定校验，不被用户租约阻断。

原生操作入口在改动Yjs之前申请相关节点租约。等待中的操作单独记录到本机草稿，成功应用、刷新原生队列并写入主草稿后才清除等待备份。连接、登录或画布切换会阻止迟到操作落入新页面；存储失败时保留等待记录并保护离页。原生历史索引在获得相关节点租约前不推进。节点新建先保存再申请，跨节点移动、连线、删除和历史操作检查全部受影响节点。

自动合并保留每笔修改的原始基线，避免远端新建节点后误判双方同时新建。只有已知基线且修改已收敛的冲突自动解除；真实字段冲突、未知基线和未证明的CAS失败继续保留草稿。CAS遇到新远端版本时最多重试3次。节点正在被占用是可重试等待，不会变成粘滞的本地草稿冲突。

验收分别覆盖真实隔离PostgreSQL的鉴权、租约并发与原子拒绝，以及双浏览器页面的生产协作组件交互。浏览器使用临时本地协议服务和合成成员/画布，未使用生产用户项目、未提交模型任务；它验证组件的传输、光标、禁写和备份，不代表完整原生应用端到端验收。用户指南截图来自真实组件的示例画布。发布检查结果在CI及本轮交付记录中核对。

各页面的平移缩放单独保留，已知基线中的viewport不参与共享节点冲突；只有视角变化时不新增快照修订。真实节点position仍按共享内容检查冲突。保存完成后，在同一页面、没有新本地输入且原生编辑器允许应用时立即对齐已保存合并结果，避免等待下一次SSE才消除显示与服务器的差异。

本地验证：154个Web测试文件共2,828项通过，生产Web构建通过；冻结资源1,198项校验通过，合同66项、指南7项检查通过。隔离PostgreSQL合并定向53项通过，随后最新任务入口10项通过，均0跳过、资源清理无错误。Go重点包race与vet通过。双浏览器页面验证了光标坐标随平移缩放转换、占用姓名与禁写、不同节点同时编辑、等待备份与释放后继续、离线草稿与重连续存、停止续期后过期并被另一成员取得。检查了390px宽的成员面板。异步取得权限后的剪切需要再次点击；触控拖动与中文IME仅有自动化保护验证，尚未真机验收。
