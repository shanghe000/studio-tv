# Studio TV 节点复制与状态管理修复验收

2026-11-05。基于 `59604de71837fb7d2c6d2c9047335d57e5a36032` 工作树；对照审计见 [节点生命周期审计](node-lifecycle-audit-2026-11-05.md)。本文记录发布前验收，实际发布状态以交付回执为准。

## 修复范围

| 问题 | 修复后的规则 |
| --- | --- |
| 新节点 ID 丢失模型版本，仍带旧任务 ID | 复制携带源节点精确的型号、能力版本和参数版本；删除旧任务、进度、失败信息及历史归属，新副本从 idle 开始，保留当前结果预览。 |
| 键盘粘贴、菜单创建副本、Alt 拖动行为不同 | 统一在原生粘贴事务前转换。保留输入边及选中集合内部边，不向现有下游增加额外输入；跨画布只保留可在复制集合内解析的边。 |
| 参考顺序仍指向旧节点 | 重映射图片、视频、音频顺序中的节点 ID、复合键和对象键。 |
| 连线校验与生成校验使用不同版本 | 连线、悬停、粘贴校验读取已恢复的精确模型绑定；不以目录最新版本替换已选版本。 |
| 相同参考数量复用错误缓存 | 缓存包含模型版本和实际素材身份；替换重复首尾帧后会重新判断。真实超限依然拒绝。 |
| 同型号重选不能修复缺失绑定 | 显式重选缺版本节点时补上可用模型版本，并清除无法归属的旧任务；正常渲染、编辑描述不会自动升级模型。 |
| 原生操作拒绝但附加模型绑定提前改变 | 接受同步修改后才登记绑定；被拒绝或尚未完成的修改不预先改变绑定。 |
| “此功能的服务接口尚未接入”无法定位 | 未接入错误标明功能名称和安全的功能路径，例如“视频重拍”；不展示查询参数、凭据或动态标识。仍返回真实 501，不伪造成功。 |
| 复制后快捷键撤销无反应 | 原生菜单/快捷键统一使用已有本页编辑事务记录；只向菜单投影撤销数量，不另存画布快照。沿用编辑权和节点占用保护。 |

旧版剪贴板缺少来源时，提示重新复制。源节点本身缺失模型版本且仍带旧任务时，要求在原节点显式重选模型，禁止根据名称猜测旧版本。复制时的临时来源信息不会写入服务端画布。
