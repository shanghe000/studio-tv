# 图片能力接入核对

后续上线更新（2026-10-07）：本文保留早期能力版本 1/2 的证据；目前图片能力已到版本 3，支持 1/2/4 张及独立节点，语义编辑与透明抠图已有真实验收。现状见 [图片工具上线记录](image-node-tools.md)、[多图验收](image-batch-canvas.md) 和 [统一功能台账](canvas-node-status.md)。正文“仅单张／工具仍需配置”不再作为当前状态。

核对日期：2026-10-06。功能编号与逐项请求／参数见 [完整模型功能表](model-function-matrix.md)。原站仅做只读核对，未发送付费生成。下表合并同一能力的子选项，不将人物预设数量当成模型数量。

## 能力边界

- **图片理解**：图片＋文字 → 文字或 JSON。Router 的 Codex 6、6.1 视觉配置已经有真实图片验证；5.6 当前按产品策略只开放文字配置。
- **图片生成／参考编辑**：文字／参考图片 → 实际图片资产。Codex 中由独立图片工具完成，不能把文字模型返回的描述、URL、Markdown 当作已生成的图片。
- **定位、分层、蒙版、透明抠图、超分、参数化相机与布光**：另有结构和输出要求。通用图片能力可以承担部分语义编辑，但不能证明精确蒙版、Alpha、坐标、层级或像素保持已经合格。

## 推理参数与版本

本轮 Router 增加相同公开 ref 的版本 2／参数 schema 2：`reasoningEffort:low|high`，默认 `low`。STUDIO 将原生 `reasoning_effort` 的 Low／High 映射到该中立字段，再由 Codex 适配器显式传入每轮 `turn/start.effort`。强度切换不改变模型、功能模板或会话归属。

原站目录的 `display:false` 确实会隐藏推理参数；此次按用户新增要求，在**原有模型参数面板**中显示该控件，而非声称原站原本有可见切换。旧版本 1 继续使用空参数，不静默升级。精确旧版本查询独立扩展，公开目录只列当前版本。

不对不存在的上游参数假装支持：当前分镜 `max_tokens`、导演 `Temperature` 与精确蒙版／图片尺寸还要按实际能力分别定义。

## 当前上游验证

官方 Codex 文档说明内置图片生成使用独立 `gpt-image-2` 工具，可使用 Codex 计划；这不是 6／6.1 本体直接输出 PNG。[官方图片生成说明](https://learn.chatgpt.com/docs/image-generation)

deployment-host pinned Codex 0.160.0 的 `modelProvider/capabilities/read` 返回 `imageGeneration:true`。隔离测试已得到真实文生图 PNG 和参考图编辑 PNG，并验证完整 `thread/read` 快照可恢复图片字节。容器需要同时挂载同版 `codex` 与 `codex-code-mode-host`；仅挂主程序会导致图片工具启动失败。

图片能力单独发布为 `codex-image-generate-v1`／`codex-image-edit-v1`，当前仅单张输出，编辑仅一张拥有的参考图；不宣称支持未验证的尺寸、批量或蒙版。文字／视觉配置继续禁用图片工具；功能 SYSTEM／DEVELOPER 模板和摘要保持原样。
