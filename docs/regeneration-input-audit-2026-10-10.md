# 再次生成、历史连线与新建节点：输入核验（2026-10-10）

项目：`prj_fc4a4d65-1088-4048-ad64-c718c3432ae4`。范围：已接通的 Codex 图片 v1–v3、H3 视频 v1–v2；没有修改冻结原生资源、其他模型或用户既有生成结果。

## 结论与修复

点击已有结果节点的“开始生成”是对该节点发起新任务，按当前输入配置生成新版本。不是自动把当前结果作为参考图，也不是锁定重放某个历史任务。NODE 执行不自动重跑所有祖先或下游。

上一轮 `1654fbf` 只恢复了输入框显示，没有验证图片再次提交的完整链路。本轮新增测试先复现：

1. 普通图生图把更远的祖先图片一起带入；已有结果的普通图生图又带入自身旧结果。
2. 文生图因自身旧图被当作输入而类型不匹配；重绘/擦除/扩图等因多出自身旧结果而报 `PROMPT_CONDITIONING_INVALID`。
3. 实际图片输入组件提交时省略远端空历史缓存、选中索引、批次来源，触发 `STALE_EXECUTION_INPUT`。已生成工具结果的普通输入框，还会重新投影直接参考图和默认透明背景参数。

修复 `9581384`（API/Web）：图片和 H3 统一隔离模型输入；当前节点的根级展示字段不当成参考素材；媒体只取直接上游，保留显式参考参数、工具标记图/姿态图、文本条件。上游媒体自身的生成提示词不重放。服务端任务快照仍保存完整图，用于来源追踪和并发校验。

修复 `335e6a7`（Web）：只为同一已生成图片、相同输出和相同远端历史补回被组件省略的缓存信息；允许已完成工具节点的直接连线投影；兼容原本有效值就是 false 的透明背景默认值补写。真实的提示词、输出、历史身份、参考图、蒙版、选择或连线变化仍受校验。

补充修复 `a7134e2`（Web）：保存时服务端保留的目标图片 assetIds/batchOrigin，只从提交前已保存快照补回，并要求旧显示素材、远端历史及保存回执匹配；不借此放宽输入或替换历史。

`f956ff5` 同时覆盖保留 image-redraw 等工具子类型的已完成节点，避免只识别普通 image-image 子类型。

## 实际模型输入矩阵

前端会向 STUDIO 提交完整或补全后的画布快照；这不等于把整张画布发送给模型。下面计数指 STUDIO 编译后传给 Router 的去重媒体附件。

| 场景 | 模型收到的内容 | 不自动传入 |
|---|---|---|
| 新建无参考文生图 | 当前提示词、合法模型参数、选择的文本/风格条件；0 张参考图 | 其他节点图片 |
| 已有文生图再次生成 | 同上；不改输入时仍为 0 张 | 自己上次生成的图片 |
| A → B → C，C 为普通图生图 | C 的当前提示词/参数，B 当前或明确选择的历史结果；无其他显式参考时 1 张 | A 的图、B 当年的参考参数、C 的旧结果 |
| A 和 B 均直接连 C | A、B 的有效结果；不同素材为 2 张 | 更远祖先；相同资产不重复上传 |
| C 显式添加其他参考图 | 直接来源加显式图片，并按模型能力校验 | 不将显式输入误删成“历史噪声” |
| 重绘/擦除/扩图再次生成 | 当前原图 + 保存的标记图，通常 2 张，保留 MASK 对应关系 | 目标节点自己的旧输出 |
| 人物姿态操作再次生成 | 当前原图 + 姿态图，2 张，保留 POSE 对应关系 | 原图更远的祖先 |
| 其他单图工具再次生成 | 当前直接原图 + 本功能的指令/条件，通常 1 张 | 自己旧结果与祖先图 |
| H3 首帧再次生成 | 当前首帧 1 张、提示词和合法 outputPreset 等 | 上次生成的视频、首帧的祖先图 |
| H3 首尾帧/全能参考 | 显式且有效的有序图片、视频、音频，按对应能力验证 | 无直接关系的祖先媒体 |
| 全新图生图节点没有参考图 | 拒绝缺失输入 | 不拿自己的旧输出或任意历史图补位 |

注意：保存的 `params.imageUrls`、`toolsSourceUrl` 等显式输入仍有意义。用户主动将旧图加入参考，旧图就会成为合法输入；不能把所有“旧图”一概过滤。重绘输入框可能把 imageUrls 从标记图投影为原图，但 toolsSourceUrl 仍保留标记图，服务端仍编译成原图 + MASK 两个附件。

## 历史、变化与失败边界

- 不改提示词、参数和来源时，再次生成沿用这些输入；不保证随机生成结果与上次一致。
- 如果上游替换图片或切换显示版本，再次生成可能使用新输入。需要严格复现旧任务时，应固定那次参考素材/历史选择；普通“开始生成”不是历史任务重放按钮。
- 明确选择的历史结果优先于新结果；不存在、删除、无权访问的历史不能偷偷回落到当前图。
- 全画布快照仍经过素材与权限检查（包括前端 freezeGraph），没有绕过损坏资产、外部临时 URL 或权限错误。此次隔离解决“误加为模型参考”，不承诺所有含无效历史素材的旧画布都能运行。
- 任务快照和祖先版本保护保留；生成期间更改输入，仍可能触发冲突保护，防止旧任务覆盖新编辑。
