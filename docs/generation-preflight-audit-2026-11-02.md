# 生成前置校验验收（2026-11-02）

状态：IMPLEMENTED。发布结果以对应 main 流水线及 deployment-host 的发布版本为准。

## 用户行为

- 连线时检查已知的类型、数量、循环依赖及可信素材限制；不兼容连线给出原因。
- 生成按钮按自己的目标和当前可见参数检查。检查中或有问题时不会提交；问题行显示节点、输入或参数，点击可定位来源节点，修改后自动复查。
- 实际提交复用按钮检查的准备逻辑，重新检查素材和权限，并保留画布版本、节点占用与命令一致性保护。
- 普通分组、画布批量、应用及实体计划在创建首个任务前完成静态检查。上传素材保留为依赖，不当作生成目标。计划内的上游输出按声明类型检查，目录中已知的输出尺寸、时长也提前校验；未知的未来输出属性不伪造。
- 尚未提交的错误不把旧成功结果或旧任务改为失败。用户明确点击后才上报前置校验诊断，自动检查不刷机器人告警。

## 检查范围

机器可读清单位于 `tests/fixtures/preflight-parity-matrix.json`。

| 范围 | 实现入口 | 验收内容 |
| --- | --- | --- |
| 模型参数 | `schema-parameters.ts`、`native-parameters.ts` | 类型、枚举、必填、嵌套字段、范围、数组、组合规则和本地引用；55 个目录夹具默认参数；未知断言明确阻止 |
| 模型和素材 | `execution.ts`、`input-media-constraints.ts`、`video-input.ts` | 模型及版本、支持类型、必需参考图、数量、文件大小、尺寸、像素、时长和必需元数据 |
| 连接与按钮 | `connection-readiness.ts`、`native-generation-readiness.ts` | 单按钮目标隔离、可见表单参数、修改后恢复、重复点击和异步响应隔离、窄屏布局 |
| 画布与分组 | `generation-readiness.ts`、Go `domain/task.go` | 节点/边/序列化大小上限、重复标识、悬空边、自连和完整画布循环；前后端素材目标分类一致 |
| 应用和实体 | `execution.ts` | 表单版本、必填字段、字段类型及范围；批量先检查后执行；不覆盖旧结果 |
| 媒体处理 | `media-job-validation.ts` | 输入/轨道/片段数量、裁剪、速度、旋转、尺寸、编码及容器兼容、可信时长边界 |
| 诊断 | `preflight.ts`、Go `observability/preflight.go` | 模型、版本、来源、字段路径、规则和安全的数值界限；不记录参数原值或未知用户字段 |

## 验收证据

- 完整 Web 测试：164 个文件、3090 项通过；TypeScript 检查通过。
- 相关 Go domain/application/http/observability 测试和 race 检查通过；真实 PostgreSQL 联调由发布流水线执行。
- 浏览器验收使用实际生产 TypeScript 模块和隔离的本地协议响应，没有调用真实模型、发送机器人消息或修改生产项目。
- 浏览器实测：缺参考图、非法可见参数均为零任务；非法视频到图片模型连线不落盘；修正参考图及参数后恢复按钮，一次点击只创建一个本地协议测试任务。
- 桌面与 390px 窄屏提示可见并换行。截图随使用指南发布：`apps/web/public/guide/images/generation-readiness.png.svg`。
- 原生冻结资源及冻结 OpenAPI 由基线和契约检查核对，未直接修改。

## 仍由服务端和运行时确认的事实

校验不能保证供应商持续可用。检查后权限或历史被修改、尚未产出的上游文件实际大小与内容、损坏媒体、未声明的音轨、实际解码/模型响应和网络故障仍需服务端确认。它们保留真实任务生命周期和独立错误提示，不能用跳过鉴权、伪造素材元数据或移除一致性保护来掩盖。

旧页面应先保存或下载草稿备份，再刷新一次启用本版本界面。
