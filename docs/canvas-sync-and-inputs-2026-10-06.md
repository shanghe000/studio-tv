## 画布同步

`GET /api/v2/projects/{projectId}/events` 保留有限 JSON 补读，`Accept: text/event-stream` 开启有界 SSE。客户端先获取一致 live-snapshot，再从其十进制字符串游标读取事件；收到变更后重新读取一致快照，三方合并本地草稿，再增量应用原生 Yjs。只有原生画布应用成功才推进已消费游标。

原生 manager 保持同一实例，远端修改不加入本地撤销栈；活动编辑、拖拽时延后应用。不同字段的修改可合并，同字段或删除冲突保留本地草稿并暂停提交。模型精确版本 sidecar、素材加载、切换项目、身份变化、迟到响应和已删除项目均按当前 attachment 校验。复用同一 manager 切换 room 时，保存的是旧项目最后观察到的草稿，不能把新 room 的图写入旧项目。

SSE 逐页读取项目归属，发送前重新校验原 Bearer、当前会话和 tv.access；空页也重新检查。每连接最多 30 秒，每次空页补读间隔 1 秒，心跳间隔 10 秒，单次操作最多 5 秒；同时受已验证的 JWT 和本地/IPAC 会话截止时间约束。每连接最多 1024 个事件和 8 MiB，每用户最多 2 条连接、每进程最多 128 条。已取消但底层仍在收尾的操作继续占用配额，防止积压。撤权停止时间受轮询和鉴权响应耗时影响，不能称为毫秒级撤销。

HTTP 提交前失败保留正常错误响应；流开始后使用没有事件 ID 的 `stream.error` 控制帧。断流重连不会把错误帧当画布事件。Web 使用带内存 Bearer 的 fetch 流，并主动取消 reader；403、删除及不可用能力按实情停止，暂时错误退避并去重提示。支持旧服务的 406/415 JSON 补读回退，不回落模拟数据。

本批次基线的节点执行状态为 `nodeStates=[]`、`nodeExecutionAvailable=false`；不把 graph 中的 status/taskId/output 视为服务端执行证据。

## 执行输入

媒体引用按稳定规则收集，明确消费 imageOrder、videoOrder、audioOrder；顺序字段用于排序，未列出的合法素材保留。首尾帧映射使用排序后的首图和末图，仍受所选能力的模态与数量约束，不意味着当前已配置真实视频服务。

原生媒体排序键为 `nodeId::URL`。保存和执行冻结时，将已登记的完整引用转换为 `nodeId::rhtv-asset:ID`；重新加载时使用当前素材 URL，还原原生排序。仅精确匹配已登记的引用，不替换提示词里的子串。动态上游与已有素材使用同一来源顺序，再应用明确排序。

显式历史选择从同用户、同作品、同源节点已完成且未删除的执行记录中解析。历史回显字段不再递归当成全部输入。选择不存在或已删除的历史时拒绝执行，不悄悄换成最新结果。输出 ID 有歧义时需要执行标识消歧；按索引选择对应当前可见历史输出列表。

未显式选择历史时，通过当前 `historyStorage.historyId` 读取权威结果批次，支持文本、结构化内容和多个媒体产物；保留用户手改、清空文字或更换素材的操作。视频、音频节点自动显示批次首个 URL 时，不能因此丢掉同批其余输出。

私有输入记录冻结来源节点、历史任务/执行/产物、产物内容指纹、素材内容版本、模态、角色和顺序。任务创建和执行绑定阶段重新检查历史及素材来源项目的存活和归属。它是执行器内部记录，不是任意用户可提交的授权凭据，也不是完整公开 InputBinding API。

浏览器隔离fixture验收证明恢复与合并行为，不代表自动找回已关闭且从未保存的旧页面，也不替代真实模型生成效果验收。


## 2026-11-02：生成操作队列与原生命令投影

普通节点和分组生成在捕获 mounted baseline 前同步提交原生本地操作队列，避免表单补丁尚未落盘时用旧输入比较新命令。视频原生命令由冻结生成器 MCe 按所选模型的声明参数构造；常规视频节点与分镜节点采用同一协议校验，不能仅因分镜标记缺失就拒绝等价投影。未声明的界面型号/比例字段以及生成器省略的历史 text 辅助缓存不应覆盖当前 prompt，也不应触发输入变化误判。

保存结果可能先通过 live-sync 应用到同一页面；已验证且恰好等于本次冻结命令的投影字段按同次操作处理，不能误报为用户后续修改。此处理仅用于比较，不覆盖当前编辑；预设和历史选择不作无条件忽略。

真实描述、参考、型号、规格或节点身份在提交期间变化时仍检查一致性。诊断分别标识 inputs.command / COMMAND_MISMATCH 与 inputs.snapshot / INPUT_CHANGED，并记录所选模型版本和固定 component 分类；不保存差异的原始文字、地址或任意用户字段路径。
