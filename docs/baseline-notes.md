# RunningHub RHTV 首页与画布复刻

原页：https://rhtv.runninghub.ai/projects/ 。采样日期：2026-10-03。

本版本沿用采样时公开加载的前端组件、样式、图标和动画。保留粒子交互、输入占位文字动画、输入框展开、模式与模型菜单、生成偏好、四类内容、搜索、悬停视频、作品详情播放器、语言选项、账户与充值对话框。包含完整静态资源、公开内容快照和会员/钱包套餐展示数据。

预览采用模拟账户，显示 Personal 与 0 余额。登录、支付、实际 AI 生成和原站私人项目未接入；不会向原站发送业务、账户或支付请求。画布节点、连线、文字、参数与上传附件保存在当前浏览器的 IndexedDB/localStorage 中，刷新后可恢复；跨浏览器、跨设备同步尚未接入。删除画布不会清理其他画布可能引用的附件文件。分享链接仅在保存该项目的同一浏览器中有效。作品视频仍从原站的公开视频地址播放。真实账号头像和余额与当前预览不同。

在本目录运行 `python3 preview.py` 后打开 http://127.0.0.1:4173/projects/ 。网站内容位于 dist/，可直接作为静态网站部署。部署配置已启用 SPA 路由回退，支持刷新任意新建画布地址。

验证：首页菜单、四类内容与搜索、语言切换、图片模型及比例、视频模型及清晰度/时长、作品详情与播放、图片附件预览；未提交真实生成或付款。

自建后端协议已整理为 v1.0.0，见 [协议说明](contracts/README.md)、[OpenAPI](contracts/openapi.yaml) 和 [旧接口迁移映射](contracts/LEGACY-MAPPING.md)。协议覆盖 71 个操作，当前后端和兼容层尚未实现；文档定义不能视作接口已经接通。


画布入口为 `/project/canvas/:id`。首页「新建项目」会创建独立项目并进入画布。沿用原生 React Flow/Yjs 编辑器、节点与弹窗组件、动画、菜单、快捷键、小地图、缩放/平移、网格吸附、节点管理、复制粘贴、删除、撤销重做和整理画布。

图片、视频、音频、3D 模型、3D 导演台、脚本、分镜、合成、画板和剪辑入口均保留原界面与前端交互。角色库包含 415 个公共角色快照，支持分类/搜索/收藏；AI 应用库包含 57 个公共应用及其输入规格快照，支持筛选、搜索和添加到画布；工作流使用既有公共内容快照。目录快照不随原站实时更新。部分应用预设参考素材是原站私有文件名，预览保留上传入口，需自行提供素材。素材库的文件夹创建、上传、重命名、移动与删除保存于当前浏览器。

已知默认参数的价格使用采样时的标准价格快照，已去除原账号免费额度。其他参数显示「待接入」；快照不是实时计价或结算依据。AI 助手、生成任务、付费与多人协同仍需自建后端，预览会提示未接入，不会执行生成或扣款。原账号平台密钥、凭据与临时签名地址已清除。公共图片、视频仍可能从原站公开媒体地址加载。

本轮画布新增接口边界另见 [画布联调说明](contracts/canvas-integration.md)。冻结的 v1.0.0 协议保持原样；普通画布快照可复用 v1，文件夹树、应用输入绑定、图执行与协同需要后续协议扩展。


剪辑面板现包含独立 OpenCut 原生编辑器（媒体、文本、设置、时间线、IndexedDB/OPFS 保存与浏览器 WebCodecs 导出），通过校验 origin 的消息桥与画布互通。5 秒 480P MP4 导出已能导回画布并刷新恢复；当前 ego 浏览器编码较慢，保留原始编码实现，未采用未通过验证的替代方案。顶部 HyperFrames 包含原生 Nuxt 页面及 Studio 静态资源；AI 会话、工作区服务器文件与服务器渲染仍待后端接入。所有嵌入页面也使用本地接口边界；禁用原服务 WebSocket/EventSource 与原 Studio 遥测。
