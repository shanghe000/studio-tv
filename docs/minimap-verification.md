# 小地图拖动修复

2026-10-04，实现提交 `cb93995`，发布标签 `studio-minimap-v0.3.3`。

原生 SVG 小地图的范围包含主画布视口，拖动时范围和估算比例会持续变化，造成缩略内容漂移和移动速度变化。源代码适配在按下时记录视口、SVG 逆矩阵及 viewBox，按固定起点计算整个手势的位移，并在拖动期间固定缩略范围。通过原生 React Flow `panZoom.setViewportConstrained` 更新视角，保持 D3、编辑器状态和回调同步；抬起、取消、失焦后恢复原生自动范围。

适配只接管 `.rh-canvas-minimap-host` 内 SVG 小地图的拖动。点击定位、双击及滚轮仍由原生界面处理；800 个节点以上使用的另一种小地图未改动。冻结的原生组件不改写；React Flow store 的结构检查集中在此兼容边界。以后替换原生编辑器版本时需重新核对该结构。
