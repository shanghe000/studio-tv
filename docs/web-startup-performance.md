## 调整边界

只更新 Web。静态 JS/CSS 使用构建产物的 gzip 副本，并为带内容指纹的自有和原生 JS/CSS 设置长期缓存；HTML 继续重新校验，runtime-config 继续 no-store。API 和资产存储请求不增加缓存。

在入口建立持续加载状态，登录门禁仍独立执行真实会话恢复和应用准入。准入后接续工作台加载提示，等原生页面真正挂载才揭幕；故障提供刷新重试。原生模块只在准入之后执行，身份失效由原门禁立即隐藏页面。

未改冻结原生资源、API 合同或七天固定会话期限；未把 UI 加载完成信号用作服务端授权。

本轮源码调整：

- 项目及文件夹目录使用目录加批量预览，不再提前读所有快照、access、任务和素材详情。预览单独存放，不建立可编辑画布、不授予权限或覆盖草稿。卡片修改按需复核权限；服务端既有 metadata 写入 CAS 语义没有扩展。
