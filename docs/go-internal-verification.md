# Go 内部版历史验收记录

本页仅记录 `go-internal-v0.2.0` 发布时的历史行为，包含当时未开放真实登录的限制，不能作为当前认证或部署状态。当前官方 SDK、SessionStatus 和工作空间授权方案见 [IPAC 接入说明](ipac-integration.md) 与 [授权边界](ipac-rbac.md)；本轮上线须另行实际验收。

验收日期：2026-10-04（Asia/Shanghai）。功能提交 `191f3e9`，发布标签 `go-internal-v0.2.0`。此记录补充上一阶段验收，不把预览数据或测试身份视为正式登录。

## 工程与运行

- 前端独立 TypeScript/Vite 工程；API 为 Go + chi + pgx。旧 Node 后端不再参与构建或运行。
- deployment-host 的独立 Compose 项目运行 Web/Nginx、Go API、PostgreSQL 17 三个容器。Go API 以非 root UID 1000 运行，运行镜像没有 Node；API 健康检查及数据库就绪检查通过。
- Web 和 API 只绑定宿主回环端口 18880/18881；数据库不发布宿主端口。数据库与素材分别使用持久卷。
- 正式部署保留原有 1 个项目、1 个素材和文件。迁移表包含 `001_core.sql`、`002_ipac_auth.sql`；旧密码会话已撤销，旧身份不自动合并到飞书身份。
- 迁移前备份位于 deployment-host `/home/user/.config/rhtv-service/backups/20261003T174959Z`，包含数据库、素材、受限环境配置及原版本号。备份和密钥未进入 Git。

- `npm run verify`：前端类型检查及 19 项测试、Go 单元测试与 vet、冻结资源和协议检查通过。没有数据库环境的本地 Go 测试明确跳过数据库测试。
- `npm run build:web`：生产构建通过。
- 原生编译资源 1198 项 SHA 校验通过；冻结核心合同仍为 61 条路径、71 项操作。协议示例 29 项接受、14 项拒绝，5 项扩展检查通过。
- 统一登录扩展 JSON/YAML 内容一致，OpenAPI 校验通过。
- deployment-host 执行 `scripts/test-api-docker.sh`：隔离 PostgreSQL 和媒体工具环境全部通过，没有跳过。测试结束清理临时容器与网络，不接触正式持久卷。日志保存在 deployment-host `/home/user/.config/rhtv-service/go-container-tests.log`。

隔离测试覆盖项目幂等、UUID 大小写及数字表示重放、画布 ETag 冲突、跨用户资源隔离、实际文件大小/校验和/MIME、签名读取及 Range、引用删除保护、运行实例重建后数据恢复。使用 ffmpeg/ffprobe 验证真实 M4A/M4V 文件。认证测试覆盖登录事务一次性和过期、签名 OIDC 交换及无效证明、会话轮换/退出/重放、CSRF 和认证来源拒绝；OIDC 签发方是测试服务，不能代表实际 IPAC 联调。

## 浏览器检查

使用 ego-browser 在同一验收 TaskSpace 检查：

- 正式服务首页隐藏充值、会员、余额、支付、社区、营销和外部服务入口。
- 正式服务点击“新建项目”进入飞书登录面板；当前按钮禁用，并明确显示“飞书登录暂未开放，请联系管理员。”，没有模拟登录或假成功。
- 显式 `preview` 模式验证新建项目进入画布、打开/关闭小地图、添加文本节点、原生输入后失焦提交、刷新后恢复同一文本。
- 画布的原站反馈外链和“按 Token 计费”提示已纳入内部版隐藏规则。原生工具栏、节点及编辑器仍由冻结资源运行。

上述检查没有穷举所有动画与所有原站功能，也不等于逐像素或 100% 交互验收。服务端画布保存通过真实数据库集成测试；正式浏览器的已登录保存流程需实际 IPAC 登录开放后补验。

## 当时开放范围与待办

正式 HTTP 检查：登录配置返回 200 且 `configured=false`；未登录项目接口返回 401；内部禁用的钱包和社区接口返回 403；未知接口返回 404。未实现的已知操作返回 501，模型调用没有供应商或费用。

**该历史版本真实飞书登录尚未开放。** 当前 IPAC 会把外部密码登录的 `amr` 也标记为飞书，缺少可信认证来源。本项目已实现要求 `auth_provider=feishu` 的接入方案，尚需修正现有 IPAC 并登记独立应用。方案见 [IPAC 接入说明](ipac-integration.md)。此记录对应的历史阶段没有改动 IPAC 源码或配置；该限制不描述后续已获授权的接入工作。

其余后续事项：正式域名/HTTPS、模型提供商和异步任务 Worker、团队协同及更多素材管理。最小 API 清单见 [内部版最小 API](api-minimal.md)。
