## 行为和边界

普通单节点提交前保存实际选用的模型、版本、参数和输入，然后用这次保存回执的项目版本申请执行。版本不一致或输入在等待期间变化时停止提交。移动节点、调整展示尺寸和无关节点修改可以保留，不会错误地替换本次冻结输入。

新任务由服务端记录节点与任务的绑定。接受、运行、失败、取消和结果保存与项目修订、画布事件在同一数据库事务中提交。关闭页面不影响服务端保存；打开页面后从一致快照恢复。浏览器不再为这些任务重复写回结果。

任务接受时冻结目标及其上游输入内容和私有节点版本。提示词、选中历史、引用内容或连线条件变化，即使随后撤销恢复原内容，旧任务也不覆盖新内容。删除后按同 ID 重建节点不会继承旧任务结果。后发起的任务优先；旧任务的真实结果仍进入历史。提交到服务端之前完全发生在本地的同 ID 删除重建由原生节点身份检查保护。

只排除节点顶层 width、height、opResize 等原生展示字段，以及 estimateTaskId、generationStartedAt、estimatedSeconds 计时字段；嵌套模型参数及输出中的同名字段仍属于实际输入语义。迁移 018 修正计时字段分类，已发布的 017 保持不变。

写回前重新检查选中历史、素材及其来源项目是否仍可用。素材结果保存为内部资产引用；不把临时下载地址持久化到画布。历史被删除、输入失效或结果使图超过保存上限时，任务结果不写回画布。手改生成文字或输出会作为内容变化处理。

客户端图上的 status、taskId 不是任务授权证据。live-snapshot 的节点状态来自匹配当前节点版本、同用户同项目任务以及持久绑定的联合检查。正常客户端写图不能伪造当前绑定的任务标识或完成状态。

## 兼容路径

脚本、APP、分组、整图、孤立工具和原生隐藏图片解析仍保留原有路径，不承诺关页后自动回写。原生隐藏图片解析有特殊的内部输入修复时序，需要单独迁移。无新增回写标识的旧任务仍按原逻辑处理，不把新版前端部署当作历史任务迁移。

画布冲突草稿仍保存在页面内存，离线恢复和独立冲突处理面板尚未实现。已有 STUDIO→Router→Codex 链路保持不变。

跨项目素材引用的数据库事务发生死锁或可重试的串行化冲突时，只对完整 Create/Save/BindInputs SQL 事务最多尝试三次，并保留上下文截止时间。此重试不包围模型提交，不因数据库锁竞争重发生成。生成资产在导入后、保存前已不可用时，保留任务终态与历史墓碑，不向画布发布失效素材。
