# 画布同步与刷新成员修正（2026-11-03）

状态：IMPLEMENTED。发布结果以对应 main 流水线和 deployment-host 运行版本为准。

## 已确认的等待与残留来源

1. 普通自动保存每次编辑重置 600ms 静默计时，连续操作没有最长等待；慢请求期间可排入多份完整保存。
2. 每个实时快照对全部素材逐项发 HTTP 请求，全部完成才可推进画布版本；不能以跳过素材权限检查解决。
3. 任意输入框有焦点时，整个原生同步批次暂停，连不相关节点的变化也要等待失焦。
4. 触发实时连接容量限制后，客户端永久退回 5 秒轮询，不会在旧连接退出后自动恢复流。
5. 前置检查提示层在存在提示时持续执行 RAF，且无关 DOM 动画会触发整图读取。
6. 页面刷新创建新随机会话，旧页面没有 pagehide 清理；成员按页面列出，短时将同一人算为两人。
7. 隐藏页面的异步保存完成后释放占用，未验证页面是否已重新可见或出现新操作，可能释放后来取得的占用。
8. 同账号 presence 最多4条长流，加上 content 2条，可耗尽 HTTP/1.1 浏览器通常每源6个连接的预算，保存与心跳会排队。隔离的跨身份三页场景也复现了这一压力边界，不能以该场景声称单账号配额可保护所有混合身份。

## 修正

- 普通保存采用 150ms 静默 / 800ms 最大等待。同一画布附件只有一个普通保存请求，期间的新编辑立即写本机草稿，完成后发送最新状态；执行、离开和明确等待保存仍使用原串行版本屏障。
- 临时网络、408/429/500/502/503/504 失败采用最多三次 1/2/5 秒重试。权限、冲突、未实现和非法输入不自动重试；撤权、账号或画布切换停止旧附件重试。
- 新批量素材接口每批最多100项，前端并行最多4批。每次快照仍重新验证每一项素材授权、删除和 READY 状态；所有批次成功且返回 ID 集合准确后才登记素材、推进快照。签名链接稳定策略不变。
- 聚焦节点本身、它之前的节点 ID 顺序、关联连线全部不变时，允许同步其他节点；否则继续延后，不替换焦点节点及其内部映射。特别覆盖最终索引相同但前序重排会导致临时删除再插入的情况。
- presence 每账号长流上限收紧为2，content 保持2，全局配额与 TTL 不变，为本部署的单账号 HTTP/1.1 请求留下余量。额外页面保留每秒有限读取；两类客户端临时配额占满后均按2/4/8/…/30秒退避探测恢复 SSE。不支持流的响应清除探测时间，避免紧循环。
- 提示层改为脏标记、尺寸观察及平移/滚动驱动的单帧更新；静止时不持续测量，无关页面动画不再读取整图。已有前置检查行为、可见布局和提交保护不变。
- 每个文档仍使用独立随机 clientId，避免复制标签页共享租约。pagehide 在无待保存操作时注销本页，待处理写入保留至安全期；BFCache 恢复建立新客户端并保留同作用域的缓冲编辑，旧答复有隔离保护。
- 在线人数按验证过的 userId 聚合。同账号真实另一页面的活动和租约保留并标注“你·另一页面”；刷新前不再更新的旧光标隐藏。旧页面迟到退出不会删除新页面或其他设备的会话。
- 隐藏释放回调重新核对可见性、活动轮次和待处理状态，避免清理新取得的占用。

## 验收与边界

自动测试覆盖持续输入、慢网络后续合并、草稿持久化、重试上限、撤权/切页、显式保存屏障、批量素材拒绝与不完整响应、焦点对象保留、配额恢复、刷新/BFCache 和真实 HTTP SSE 取消。批量接口及旧页面退出隔离另经一次性 PostgreSQL 数据库验证，不使用生产项目或真实模型。

浏览器协议夹具使用真实前端服务模块、冻结原生 CSS、最小 YMap/YArray 端口与本机 HTTP/SSE。它验证双页交互和连接生命周期，不代表已在生产 React/Yjs 中执行模型生成，也不把本机传输时间作为公网延迟承诺。

权限、CAS、本地草稿、节点占用和相同字段冲突保护均保留。网络不可用、正在输入的同一对象变更和真实另一页面仍占用节点时，仍应等待或提示具体原因。

浏览器补充结果：双页 HTTP/SSE 中保持 A 的文本、焦点元素和 caret=22 时，B 的位置由450更新到486；刷新旧成员从服务端移除且只记录一次旧ID退出，同账号两页仍显示“在线1人”。旧光标隐藏后，新活动协议帧再次显示“你·另一页面”。一次503后自动补发成功；2秒慢 PUT 期间10次后续改动持久保留，最终只补发一个最新保存。截图同步至使用指南。
