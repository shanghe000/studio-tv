## 接入与执行边界

- 图片公开引用不变：`codex-image-generate-v1` / `codex-image-edit-v1`。最新能力和参数版本均为 `3`，支持 `count=1|2|4`、`transparentBackground:boolean`。每张实际返回图片对应独立节点；旧版 1/2 节点和历史结果仍保留原版本。
- 新增 9 项通用预设、18 项角色选项、162 项人物选项。依据公开标签编写 STUDIO 自有语义提示词，不声称获取原站隐藏提示词。角色/人物目录与默认风格分类独立，避免原生菜单回退导致无资源请求。
- 内置四种风格参考图通过固定字节、来源与 SHA-256 清单转换为本项目真实资产；服务端从受控目录或当前用户资源解析，不接受伪造 SYSTEM 风格内容。
- 修复原生图片工具、普通图片表单以及增强占位节点的提交差异；只补齐已验证的缺省字段和同资产元数据，保留源图、提示词、连线及保存版本的过期提交保护。
- 二次编辑取直接上游当前结果作图片输入，不把更早祖先图片混入；完整祖先快照仍参与变更校验。普通多参考图生成保留原有多图语义。
- 重绘、擦除、扩图以原图与合成标记图进行语义编辑。MASK/POSE 明确绑定同请求原图；当前 Codex 没有原生像素蒙版参数，区域外内容也可能改变。
- 抠图强制透明 PNG，并在执行和恢复时检查透明与可见像素；不透明图片或全透明空图不计成功，不自动重试。
- 角度与打光表达生成意图，不是三维几何重建或校准光学模拟。全景、扩图和人物调节不保证指定像素尺寸。
