# 新节点、连线与输入组合检查（2026-11-04）

## 最终产品与状态架构

用户明确要求取消前台版本管理，并允许舍弃实时多人编辑。本轮最终实现为**服务端单一权威文档、每张画布一个编辑会话、浏览器显示镜像与未确认操作队列**，不是只隐藏旧草稿窗口。

- 画布不再安装多人 presence、协作光标、逐节点占用和输入/鼠标事件重放拦截。编辑连接30秒有效、10秒续约；同一项目第二个页面等待，服务端同时拒绝其操作及旧快照写入。
- 正常画布编辑使用独立 `canvas-operations` 协议。客户端从相邻两次实际原生操作观察中生成节点/连线的字段操作；服务端在当前文档的项目行锁内原子应用，不要求浏览器持有或提交版本号，不做本地/远端完整画布三方合并。
- 未确认操作逐批保存在本机，每批独立键，只存操作及身份/顺序，不保存一个可独立分叉的完整画布。断线重试和刷新确认沿用相同批次编号；收到可验证回执后才移除该批操作。账号切换不重放前一账号内容。
- 后台生成结果与前台操作写入同一个服务端文档。客户端的描述修改只更新其实际修改字段，不用旧输出覆盖新的生成结果。模型生成提交仍检查当次冻结输入，不把后台校验变成假成功。
- 公开版本比较、草稿合并、选择本地/服务器、导入导出备份和旧救援页面均撤下。底层旧格式读取/维护工具留在非公开工具目录，正常实时编辑不调用旧三方合并。未上传素材的准备阶段仍保留在原页面，准备完成后才记录可提交的不可变操作。
- 素材物化和跨项目授权导入发生在记录不可变操作之前，已经尝试提交的批次不能更改内容后复用编号。

协议和边界见 [画布操作扩展](../contracts/canvas-operations-extension.md)。

## 排查发现的缺陷与输入边界

- 原生表单省略空闲节点的 `routerParameters` / `userPromptSnapshot`，挂载观测却没有记录这一投影。随后同人正常换模型，合并器会把字段省略当成远端参数变更，形成 `MODEL_PARAMETERS` 并阻塞整图。现在只在同模型、版本和所有输入/选择/缓存严格相等的挂载或已应用观测中恢复省略；不拿较新的 ETag 修补旧 pending 基线，真实并发参数变化继续保留。
- 新节点加号使用 PointerEvent，ReactFlow 端口使用 MouseEvent。等待占用后须按实际控件协议重放，不能只补鼠标事件，也不能双发两套协议。首次图标点击还须支持 SVG 目标；成功、取消和失焦路径均检查原生监听与定时器清理。
- 正常 CAS 追赶已由保存层保留修改并有限重试，412 本身不再显示“另一处更新、自动保存暂停”。确有重叠修改时仍保护内容。
- 视频连线校验与生成准备共同读取当前直接素材和明确引用，断开的旧执行缓存不计入新输入；内联引用与连线合计计数。源节点贡献当前显示的结果，不递归拿它生成时的祖先素材。
- 图片生成参考支持原生历史选择与显式排序；未知历史、伪造引用及特殊端口保持检查，不能借兼容投影放行。样式引用在排序后追加，避免错误重复计数。
- 导入或历史图中的重复连线，在生成前明确定位为拓扑问题；自连、悬空引用、循环、模型类型/数量/素材规格和参数校验继续生效。
- 同步诊断包含当前模型/版本（可解析时）、阻塞原因、检查序号及固定冲突类别/相关节点。原始路径、任意字段名、描述正文和媒体 URL 不进入诊断。机器人同步检查告警不再要求用户先处理版本草稿。

## 关键场景矩阵

| 场景 | 编辑与同步预期 | 生成输入预期 | 验证方式 |
| --- | --- | --- | --- |
| 旧空闲节点换模型，再新增图片/视频和参考连线 | 同人修改自动保存，不阻塞其他节点 | 原有参数不被旧回执覆盖 | 存储回归与原生页面 |
| 新建目标后连接，或由加号拖出创建目标 | 首次操作等待占用后继续，无需预先悬停 | 已保存的实际节点和边形成输入 | 原生 Pointer/Mouse 交互 |
| 保存响应之前继续连线/改模型 | 合并后续本地操作，追赶完成继续保存 | 提交先等本次操作落地 | 实际 CAS/SSE 客户端及延迟测试 |
| 图生视频断开、重连、再次生成准备 | 结果与历史保留 | 当前图片；缺少时明确拦截 | 冻结命令投影与实际执行适配器 |
| 文生视频带有已断开的旧媒体缓存 | 可以新增文字连线 | 不把旧媒体当新输入 | 连线与生成参考一致性回归 |
| 图片/视频历史结果接入新节点 | 原结果保留 | 只读选中的可用结果 | 冻结历史/媒体读取函数 |
| 首尾帧及多参考排序 | 连线先后不隐式颠倒显式顺序 | 按控件中的参考顺序与样式追加规则 | 冻结排序函数及提交回归 |
| 内联引用加连接素材 | 不超限才允许新连接 | 两种来源合计，不漏计 | 连线校验与准备回归 |
| 自连/重复/循环/悬空/类型不支持 | 新连线提前拒绝，历史坏图提交前定位 | 不创建任务 | 拓扑及前置校验回归 |
| 第二编辑页面、未知保存结果 | 第二页不写入；原编号确认，不以假成功覆盖 | 同步未确认前不提交 | 独占会话与幂等回归 |
