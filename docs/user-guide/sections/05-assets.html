个人资产与团队资产

顶部“资产库”用于保存、分类和共享创作素材。

{{figure:overview-assets}}
  1. 1
    选择资产范围个人资产整理自己的素材；团队资产查看和使用所在团队共享的内容。
  2. 2
    选择团队在下拉框切换团队。进入文件夹后，通过上方路径返回上级或全部资产。
  3. 3
    添加团队成员团队成员 → 添加成员 → 搜索同事 → 选择权限。可搜索已通过飞书登录 Studio TV 的同事。
  4. 4
    整理与发布“新建文件夹”建在当前团队、当前目录；“发布到团队”从个人素材或已存节点中选择内容，按需改名后发布，个人原件保留。
  5. 5
    创建与管理团队进入“团队管理”创建团队，或选择已有团队查看资产、管理成员。
只读成员查看团队资产，并导入项目使用。
可编辑成员在只读权限基础上，还可发布和整理团队资产。

把资产用于创作在资产条目中选择导入项目的操作；画布左侧“资产”用于复用已保存内容。团队资产权限与项目成员权限分别设置。

下载素材画布、历史或资产条目的单个媒体下载会按实际文件类型保留图片、视频或音频后缀，例如PNG为.png、JPEG为.jpg。标题中的中文、括号和版本号会保留；批量下载仍使用ZIP。

关闭与返回添加成员、发布素材等弹窗完成后回到来源页面；取消可放弃本次操作。浏览器后退用于返回此前页面。
