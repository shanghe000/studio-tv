02

在画布中生成与编辑

选中节点后，下方会显示可用模型和参数。先生成初版，再针对满意的结果继续编辑。

{{figure:overview-canvas}}
  1. 1
    添加内容点击左侧“＋”添加文本、图片、视频或脚本策划节点；已有文件可上传，也可从“资产”复用。
  2. 2
    需要参考时先连素材把上游素材节点右侧输出端连到生成节点左侧输入端，也可在下方素材区添加已上传文件。纯文字生图不需要参考。
  3. 3
    选模型、写描述按用途选择模式与可用模型，写清主体、场景、动作和希望保留的内容，再选择输出规格。H3动作迁移只使用人物图和动作视频，不需要提示词。
  4. 4
    生成与回看点击“开始生成”，在节点中查看结果。左侧“历史”可查看、下载和复用旧结果；满意后再继续编辑或加入剪辑。
{{gallery:s2-canvas-basics}}

上传图片时自动无损压缩选择、拖入或粘贴静态 PNG 时，画布会在浏览器中尝试缩小文件，保持原分辨率、透明度、色彩和方向。已充分压缩的图片可能几乎没有变化。JPEG、WebP、动图、视频和音频保留原文件。此流程适用于新上传的素材。

看清是导入限制还是参考限制普通画布按无损处理后的文件大小检查，单张图片最多 50 MiB。用作生成参考时，页面按实际上传大小和所选模型分别检查。例如 H3 单张参考图最多 10 MiB；若仍超限，生成前会提示具体素材、实际大小和允许值，请换用符合限制的文件。

生成前先检查：看到原因、修正后再提交

选中节点或修改输入时会在后台检查模型、当前参数、连线和参考素材，不自动弹出问题面板。检查未完成或输入不符合要求时，生成按钮暂不可执行；将鼠标移到按钮或用键盘聚焦，可查看简短原因，点击“详情”或尝试生成时再展开具体问题。说明不会挤进模型和生成按钮所在的操作行。点击“查看输入”或“查看参考素材”可返回相关内容；点击画布其他位置会收起说明。修正后自动重查并恢复按钮，临时网络故障恢复后也会继续检查，无需删除节点或重新打开页面。

连接与选模型不兼容的素材类型、超出当前模型允许数量、错误端口或循环连线会被拦住并说明原因。选模型时，不兼容的型号会灰显；可以先选择模型，再补齐参考素材。尚未上传完成或缺少有效时长、尺寸等必要信息的素材，需要先处理完再生成。

新建后继续连接可以先新建图片或视频节点再接入素材，也可以从节点右侧加号拖出连线创建目标。取得画布编辑连接后可直接操作，无需先悬停或逐个节点等待权限。参考数量同时计算连线素材与明确添加的引用；生成结果作为新参考时，按当前选中的结果和排列顺序读取。

{{figure:canvas-reconnect-native}}

分组与批量先检查整批当前可确定的输入，再启动第一个任务；上传素材只作为输入，不会被当成生成节点；无关分支的问题不会阻止当前分组。依赖上游生成结果的节点按分组计划处理，实际结果产生后仍会检查其素材。普通节点单独生成时，不能借用另一按钮的未执行计划。

断开、重连与再次生成生成完成后可断开原来的图片或文字连线，已有视频结果会保留。重新连接素材后，在同一个视频节点再次点击生成即可；当前连线和明确添加的引用决定这次输入，不沿用已断开的旧参考。图生视频缺少图片时会在提交前提示补齐，文生视频按当前描述和文字连线生成。编辑或连线仍在同步时，生成会先等待本次操作落地。

复制节点后继续生成“复制节点／粘贴节点”、“创建副本”和拖拽复制会保留所选模型及参数、当前结果预览和参考顺序。在同一画布复制单个节点时保留输入连线；复制多个节点时也保留片段内部连线，不会给原有下游节点额外添加输入。副本使用新的节点和生成任务，不继承原任务的运行状态、进度或历史记录。粘贴后可直接修改描述再生成，保存后刷新仍保留这份配置。已生成图片的副本仍保留生成面板，不会因为保留结果预览而变成只有素材工具的节点。跨画布粘贴只保留复制片段内部可成立的连线，外部参考需重新连接。

复制内容需要重新确认时旧剪贴板缺少来源信息时，请在画布中重新复制。对于以前已丢失模型版本的节点，需要明确重新选择模型后再继续，系统不会擅自换成最新版本。替换参考素材、调整顺序或切换模型后会重新检查兼容性；真实超限仍需移除多余素材或换用支持该数量的模型。

使用 Ctrl/Cmd + Z 撤销，Ctrl/Cmd + Shift + Z 重做，节点与连线按同一次操作恢复。刷新后从服务端恢复已保存内容，刷新前的撤销记录不会跨页面保留。

{{figure:canvas-node-copy}}

功能尚未接入时未开放的工具保持灰色，悬停可查看原因。仅选中视频节点不会因为尚未开放的分镜配音预设而弹出“视频重拍”错误。实际使用不可用功能时，提示会说明对应功能，便于准确反馈；这与模型参考数量超限、生成任务失败属于不同情况。

“未提交”与“运行失败”输入校验不通过时不会进入生成队列，也不会清空已有结果或把原节点改成生成失败。明确点击生成而被拦截的记录会保留型号、版本和具体输入项，便于排查；自动检查不会反复发告警。模型服务超时、生成结果损坏等运行中的问题会按实际任务状态单独提示。

在多个页面打开同一张画布

在自己的标签页之间切换用同一账号在多个标签页、浏览器或电脑打开项目，每页都能编辑。任一页新增、移动或删除节点，其他联网的页面会跟着更新。刷新或关闭一页不会让其他页变成只读。新电脑登录后打开项目，就能看到服务器已保存的节点、连线和结果。

交给同事编辑项目所有者可在“项目成员”给同事可编辑权限。看到同事正在编辑时，点击“申请编辑”。对方选择“保存并交接”后会留在原页查看，你会在当前页看到已保存的内容并开始编辑。申请可以取消，对方也可以选择“暂不交接”。只读成员请联系项目所有者授权。

{{figure:canvas-handoff-approval}}

掉线或关页关闭一页不会中断自己其他页面的编辑。向另一账号交接时，仍在线的页面先提交改动；已失联的页面在短时凭据到期后不再阻挡交接。设备完全离线时，画布暂时只读，已产生的待保存修改会保留，恢复联网后自动恢复编辑。另一台电脑只能看到已到达服务器的内容；恢复连接后可安全补传的改动会继续保存。在线页面同时改不同字段时，两处改动都会保留；改同一字段时，以服务器最后接受的那次修改为准。

编辑与同步拖动节点时，自己的画布跟随鼠标。松手后，其他已打开的页面会显示最后落定的位置。新增节点、删除连线和调整参考顺序也会自动同步。连续输入会定期提交。网络繁忙时合并尚未提交的后续改动，临时网络或服务异常时，改动会留在本机并自动重试；离线期间暂停发送，恢复联网后自动继续保存，无需再改动一次来触发。持续异常时会提示一次正在等待自动保存，画布仍可操作；尚未保存的改动在其他设备上暂不可见。切换标签页时保持健康的同步连接；休眠唤醒、浏览器后退返回画布时，会检查连接并补齐未收到的更新。其他节点的进度和独立编辑不会仅因整张画布的更新而阻止当前节点生成。输入框保持焦点时，不相关节点仍可同步；当前输入节点、其顺序和连线变化会受到保护，结束输入后再补齐。

打开较大的画布只要内容仍在持续加载，页面会继续等待，不因加载总时间较长而重新开始。临时连接或素材查询异常会自动重试；加载界面的“重试”只在尚未进入可编辑画布时重新连接。登录过期或编辑权限被取消时仍需按页面提示处理。

自动保存

网页只呈现编辑、画布占用和必要的同步状态。创建节点、连线、修改描述和重新生成的保存顺序由系统处理，无需管理版本或比较本地与服务器内容。同一账号可以在多个浏览器或标签页同时编辑。后台标签页重新打开时会自动接续；其他已连接页面仍可编辑。若久未关闭的旧网页提示更新，请保留原页，在同一浏览器的新标签页打开这张画布。系统会尝试接续旧页已记录的修改；同一处内容如果后来又被编辑，不会被旧页覆盖。网络恢复后会自动继续同步；若仍提示有内容未同步，可点击“重试同步”。保存未成功或设备存储不可用时，请保持页面打开并联系管理员，不要清理浏览器数据。

修改后直接生成修改描述、参考素材或输出规格后，可以直接点击生成；系统会先保存当前编辑，无需等待自动保存计时结束。已有历史结果的视频节点也可继续修改描述、分辨率和时长后再次生成，无需删除或重建节点。

文字与参考图片一起输入普通图片生成或参考编辑节点可以同时连接文字节点和参考图。上游文字的富文本、段落和表格会按编辑器的文字转换结果参与生成前校验，不必为了消除“描述不一致”而删除格式或重建节点。提交期间若又修改了文字或参考素材，系统会保留新编辑并停止旧命令，请确认当前内容后再提交。

生成前校验与日志编号输入不符合所选模型要求时，页面会显示型号、版本、具体不支持的输入和调整方法。素材超限会指出第几项参考、实际大小或时长，以及允许的范围；请先移除不支持的素材或连线、补齐参考，或压缩裁剪后再提交。此时任务尚未进入生成队列。若问题仍在，请保留提示末尾的日志编号，反馈时可据此追查当次型号、版本与失败输入；分组生成会记录实际出错的子节点。机器人“提交未通过”详情也会显示对应原因。

实际尝试提交并报错时，日志会保存当时的页面状态，包括所选节点、参考连线、同步进度和按钮状态。反馈时提供日志编号即可。诊断不包含描述正文或素材下载地址。机器人会分别提示同步检查、输入校验和任务自动重试。

机器人状态提醒“任务自动重试”表示任务还会继续处理，请勿重复提交；“画布同步待完成”表示生成尚未提交，系统需要继续完成同步；“提交未通过”表示前置检查拒绝；只有终态失败或超时才使用“生成失败”。

怎样选模型与参考

全能参考视频的精确时长选择自部署“MiniMax H3 · 全能参考（含视频）”后，可在“选择视频生成时长”右侧下拉框选择5～15秒中的任意整数秒，也可以逐秒拖动滑条。例如参考视频是12秒，可直接选择12秒生成。系统会在编码前同步裁去模型帧数对齐多出的尾部画面和声音，不改变播放速度、不二次压缩。参考视频可为2～15秒，输入时长和生成时长分别校验；小于5秒的输出与小数秒暂未开放。已有节点可直接重新选择时长后再次生成，历史视频保持原样。

纯文字生图可选 MOSS-Image · 生图、Z-Image-Turbo、FLUX.1 [dev]、FLUX.2 [klein] 9B／4B、Codex 图像工具·生成。MOSS-Image 位于自部署模型中，无需个人 API Key。
参考图编辑可选 Qwen-Image-Edit-2511 或 Codex 图像工具·参考编辑。添加图片，写清“保留什么、修改什么”。
视频模式文生视频只写描述；首帧或尾帧放入1张对应图片；首尾帧需放入起点和终点2张图；全能参考按所选型号添加图片、视频或音频。某些型号仍要求视觉参考。参考顺序与用途以面板说明为准。
H3 文戏／武戏MiniMax H3“单采极速文戏”面向人物表演和细微动作，“最强武戏”面向动作场面；两项都在全能参考中选择。
TR 极速双采（待手测）全能参考中选择“H3 · TR极速双采pika（修复网格·待手测）”。添加1～6张参考图，可分别选择六种比例与480P／768P／1080P（1088对齐）／2K分辨率，时长固定8秒、24fps；另保留1920×1088原规格。不接受音频或视频参考，效果待用户手动确认。
20／30秒长片全能参考中可选“MiniMax H3 · SGUN潜空间连续长片 · Hybrid INT8”。保留24fps的约20秒／30秒，并分别选择比例与分辨率，合计24种尺寸；适合同一场景、连续镜头与小幅自然动作。

MOSS-Image 怎样生图添加图片生成节点，在文生图模式选择“MOSS-Image · 生图”，填写必需的画面描述后生成。无需连接上游图片或视频；要根据已有图片修改内容，请改选参考图编辑模型。MOSS-Image 每次固定输出1张，可选的真实尺寸为1024×1024、1344×768、768×1344、1152×864、864×1152、1536×656。尺寸按模型的16像素网格对齐，横竖宽屏与常见比例略有差异，以菜单中的实际像素为准。

空视频节点先看材料提示视频还没有结果时，节点内会说明需要什么参考、怎样连接，并显示已连接或仍缺少的素材。把图片／视频节点连到左侧输入端后，再从下方模型菜单选择可用入口；首尾帧需要2张图片，动作迁移需要人物图与动作视频。参数面板顶部的“生成所需素材”列出数量、时长和人物要求。H3完整动作时长版还会在生成区直接说明素材数量、是否已连接，以及无需提示词或遮罩。

参数面板与连线视频参数面板会随窗口位置调整，并避开顶部项目标题和本节点的视频工具栏；可用高度不足时，可在面板内滚动查看材料、参数和生成按钮。失败卡片仍可从左右端口连线；重试前先补齐所选模型需要的材料。

在视频卡中制作 H3 分段长片

选中普通视频生成卡，在参数区展开“H3 分段长片”。展开后只显示长片编辑区，收起后恢复普通视频参数。共用描述、参考素材与各段剧情共同决定内容；参考图、视频和音频沿用当前视频卡的连线及排列顺序。断开旧连线或重新排列后，下次保存与生成会读取当前素材，不沿用断开的参考。

{{figure:h3-segmented-longform}}
  1. 1
    设定整片与分段填写长片名称、全片共用描述，并选择服务实际提供的比例和像素规模。逐段写画面描述、时长和种子；留空种子时由服务决定。面板显示计划总时长，生成后显示实际像素和帧数。
  2. 2
    保存并生成有效编辑会自动保存，也可点击“保存设置”；状态文字会区分待保存、已保存与提交失败。点击“生成全部分段”前会先保存本次编辑。生成时区分整项任务、当前段和处理阶段；“本段完成后停止”保留已完成结果，只停止本长片后续分段，不中断正在生成的段或其他任务。提交模型、等待确认和合片期间也会保持输入锁定。
  3. 3
    逐段回看、重抽和采用展开分段查看每次真实生成的结果、种子、帧数和尺寸。可预览或按原规格导出，选择“采用此结果”后用于后续续接和合片，也可“撤回采用”。“重抽本段”始终使用当前填写的本段描述、时长与种子，其余高级设置、参考素材和共用描述默认沿用原结果。需要一并换成当前设置时，勾选“重抽使用当前高级设置、参考素材与共用描述”。“从本段重做后续”用于前段改动后的重新续接；也可明确选择“保留后续旧片段”，但接缝、人物或道具可能不一致，需要回看确认。
  4. 4
    续拍与合片点击“添加续拍段”，填写新增剧情和时长后点击“续拍新增分段”，提交并生成后续剧情。新增段在提交续拍前只属于本页待提交输入，尚未保存到服务器。同一续接链的分辨率锁定；前段或参考改动使旧后段失效时，页面会提示需重做。每段采用一个与当前链一致的有效结果后，点击“合并已采用分段”，完成后可预览与原规格导出合片。单个输出文件同时受云端生成和平台归档限制，以面板显示的较小值为准；当前云端限制为512 MiB，不表示可以生成1 GiB文件。

高级采样与续接高级区域只列当前服务实际支持的控件，包括采样步数、采样器、调度器、降噪、SIGMAS、LoRA、注意力、上下文、动态掩码、防漂移与预览设置。选项以服务返回为准；不支持的组合会在提交前指出。自定义数组或对象需使用有效 JSON；更改 SIGMAS 时，实际采样步数以输入序列为准。“云端采样预览”控制云端工作流的预览开关；Studio TV 当前显示生成进度和完成后的分段视频，不显示采样中的实时画面。

分辨率与实际时长可用480p／720p／768p／1080p预设按当前比例换算像素规模，按钮同时显示原生实际宽高；720p、1080p等会近似对齐到32像素网格，以保存后显示的像素为准。同一已生成续接链的尺寸锁定。当前最多100段，固定24fps；H3采用原生帧网格并裁去续接上下文，计划秒数不等于精确导出秒数。超过15秒的单段及各类高分辨率组合尚未逐项完成真实效果验证，请先用短段检查显存、耗时与画面，再决定是否继续。

参考视频与配对音轨“当前参考素材”按输入顺序列出名称和类型。可连接最多9张图片、3段视频、3份独立音频，另为这3段视频分别配一份音轨，共最多18项参考。音频用途默认是“独立参考音频”；需要对应某段视频时，在该音频下拉菜单选择“参考视频1／2／3的音轨”。菜单仅列已连接的视频，每段最多配一份。重新排列视频后配对仍跟随原视频；断开原视频时会提示失配，请重新连接或改回独立参考，不会把音轨自动转给另一段视频。

恢复任务关闭参数区、重新打开视频卡或刷新页面后，面板从服务读取该视频卡的长片与候选。提交时网络中断会显示待确认操作，使用“重试上次操作”确认原任务，不会换一个请求重复生成。仅收到提交回应不代表视频已完成，请以任务状态和可播放结果为准。

模型灰显时怎么处理先查看悬停原因。“需要连接上游节点”表示应先补齐素材；“未配置 API Key”时，在“API 服务”分页点“配置 API Key”，进入个人账号抽屉保存对应厂商的 Key。若提示“暂未开放”，则该服务尚未开放。已选型号变为不可用时，生成按钮也会禁用，悬停可查看原因；描述、素材和参数仍可修改。模式标签可用于导航，能否提交仍以所选模型和材料要求为准。

官方视频 API：先看可用状态，再选模式

混合来源的模型菜单上方可切换“自部署”与“API 服务”；只有一种来源时可直接选模型。视频菜单的各分页仍按文生视频、图生视频、全能参考、视频编辑分类。切换分页只改变显示的目录，不会自动更换已选模型。自部署模型使用已部署的服务，无需个人 API Key。已接通的托管文字／图片服务沿用原有调用方式，只有标明需要个人 Key 的厂商才需要配置。

模型列表操作型号较多时，在展开的型号列内滚动，可查看并选择最后几项。也可用 Tab 将焦点移到模型按钮，按 Enter 或空格打开模型列表。焦点在列表顶部的来源分页时，可用左右方向键切换“自部署／API 服务”；切换来源不会提交生成。

官方目录包含36个按型号与功能区分的入口：4档 MiniMax H3 各有文生视频、首帧、首尾帧、尾帧、全能参考；4档 Seedance 各有文生视频、首帧、首尾帧、全能参考。个人账号未配置对应厂商 Key 时，相关入口为灰色，悬停可查看原因。从菜单的“配置 API Key”或右上角个人账号 →“模型 API Key”，保存 MiniMax 或 Seedance 的 Key；同厂商全部已接通型号会自动匹配，无需重复填写。MiniMax 需使用按量计费 API Key（Coding Plan Key 不适用），并选择所属的国际或中国大陆地区。

保存与收费Key 仅用于当前账号的任务，保存成功后输入框会清空，页面只显示脱敏值；替换时输入新的 Key。保存不会发起生成，也不验证余额和调用权限。实际调用由厂商按账户计费；生成失败时，节点会显示余额不足、鉴权失败、额度限制、素材不符合要求等原因。按提示充值、修改 Key／地区或补齐素材后再重试。移除 Key 需要再次确认，并可能使相关未完成 API 任务无法继续查询。

生成前查看费用选择 API 型号、分辨率、比例和时长，并连接或添加实际使用的参考素材后，在视频参数区、生成按钮上方查看“预估厂商费用”。改变规格或素材后，金额会重新计算；展开“计费规则与来源”可查看组成、限制和官方价格页面。查看预估不会提交生成，也不会查询或扣除厂商余额。

币种与地区MiniMax 国际地区按 USD 显示，中国大陆地区按 CNY 显示，自动使用个人设置中已保存的 Key 所属地区，不做固定汇率换算。还没有配置 MiniMax Key 时，暂按国际地区 USD 公开价预估，并明确提示“地区未确认”；保存正确地区后会刷新。Seedance 按火山引擎的 CNY 公开价估算。

MiniMax H3 怎样计费费用包含输出视频秒数、输入参考视频的实际总秒数，以及超过免费数量的参考图片。H3、Highspeed、Lite 每次前5张参考图片免费，Max 每次前2张免费；超出部分按所选型号的每张单价计入，输入音频免费。Max 的参考视频秒价与输出秒价不同，以面板列出的单价为准。首帧和尾帧图片也计入实际参考图片数量。

Seedance 怎样计费按所选型号、分辨率和是否含输入视频，使用对应的每百万 token 单价。基础估算 token＝（输入参考视频总秒数＋输出秒数）×厂商公布的输出宽×高×24fps÷1024，因此分辨率、比例、时长和参考视频都会影响费用。MiniMax 的超额图片规则只适用于 MiniMax；Seedance 当前公开规则没有单列参考图、同步音频或返回尾帧的额外价格。含输入视频时还有最低计费 token 限制，当前完整下限表尚未核验，因此只显示基础估算起价，不承诺完整费用。

怎样理解金额状态“预估”是当前已知规格的公开价计算；自动比例或智能时长未确定时，会显示估算范围；显示“起”时仅包含已知计费部分，实际可能更高，没有保证上限；素材未就绪或暂时无法报价时显示“费用未知”，不能视为免费。预估不代表账户优惠、资源包、免费额度或真实扣费，最终以厂商账单为准。自部署模型不显示厂商 API 费用预估。

动作迁移与人物替换

长片描述怎样分段SGUN 长片至少添加一个图片或视频参考。可用一段连续描述，也可用独占一行的 --- 分段：20秒写2段，30秒写3段，逐段写清姿态和动作如何承接。同场景的小动作更适合；复杂打斗、快速运镜、跨场景和对白连贯性仍需另行尝试与审片。

看懂生成进度“排队中”表示等待处理；普通任务的采样百分比只表示采样阶段，到采样 100% 后仍可能继续解码、保存。SGUN 长片显示“分段生成中”，中途不显示全片百分比；等完整成片保存后再查看。刷新后可从原项目与历史继续查看已生成结果。

视频历史左侧“历史”中的“视频历史”显示已保存视频的封面，普通视频与分段长片都可回看。悬停可播放，点击“查看”打开预览；“使用”将旧结果带回画布，“复制提示词”复制该次描述，“下载”保存原视频。封面暂时无法加载时会在卡片内说明，不会把封面替代原视频或改变已有结果。历史窗口长时间打开时，视频链接会自动更新；网络恢复后会重新检查。链接暂不可用时，对应操作会暂时禁用并提供重试。画布暂不可编辑时，“使用”不会加入未保存的节点，恢复编辑后可继续操作。

提交后能否停止模型标明不支持停止时，已提交任务的取消按钮将禁用并提示原因。请等待任务完成；关闭助手、离开画布或刷新页面不会终止已经接受的视频任务。

解析选图 →“解析”查看画面描述；局部识别先点“识别”，再点击图片中的位置选择元素，据此修改提示词。
分镜大师选图 →“分镜大师”→ 按用途选择多机位、剧情推演、布光、镜头意图、情绪、天气／效果、空间层次或三视图 → 检查出现的浮动条或面板中的描述，再点击生成。
人物调节选图 →“人物调节”→ 选择表情、视线、嘴形、姿态、形象或妆容 → 调整选项并生成。拖动结果图片可调整位置。点选结果后可修改参数并再次生成，首次提交被拒时也可在原节点重试。图片靠近视窗边缘时，参数面板会调整位置。姿态可结合骨架参考。
角度与打光“角度”中调左右、俯仰和远近；“打光”中调方向、高度、颜色与强度，再生成新图。
区域与背景重绘：标出区域、填写修改要求并生成；擦除：标出要去除的区域再生成。扩图：调整画布与原图位置，再生成。抠图、去文字、换背景按各自面板操作。
画质与放大“增强”会生成式重画细节；“高清”和“放大”共用 SeedVR2 的 2 倍放大。SeedVR2 输入图片长边须不超过 1024 像素，输出长边不超过 2048 像素。
全景图选图 →“全景图”→ 选择预设并生成；也可从图片生成面板使用文生全景。全景结果可拖动视角、调整视野并截屏回画布。
本地整理裁剪、镜像、旋转、调色和标注用于整理图片。选择“4宫格裁剪”中的“仅裁剪”会创建四张图片，可单独移动、连线或解组。组内只有素材时，“整组执行”呈灰色。选择“创建分镜格子”则可调整格子顺序并合成新图。

当前未开放的能力

首页视频直出、通用动作复刻、AI 应用、画布工作流、SkillHub／技能／插件，以及语音／音乐、3D 模型／世界生成暂未开放。文生视频需选择已配置的官方型号；指定的四个动作入口按上方说明使用。生成视频请从画布视频节点或画布助手的视频模式进入。

图片“编辑元素”，以及视频重拍、解析、修复、深度、专门画质处理、人声／环境音分离和配音预设暂未开放。原生工具栏、“更多”、添加节点和文本选区的快捷入口按实际能力开放。灰色按钮可悬停查看原因；纯文字生成视频需当前账号已有可用文生视频型号。历史画布仍可查看已有解析结果或重新上传 3D 文件；尚未接入的 3D 生成重试、解析确认和复刻继续导出也会置灰。
