3D 导演台与画板

画布左侧“＋” → 导演台 → 打开3D导演台，用于安排角色、场景、灯光与机位。

导演台的 AI 识图与文字自动布景暂未开放，请手动布置场景。预览、调整镜头和已有场景不受影响。

{{figure:overview-director}}
  1. 1
    布置场景左侧切换角色、模型、灯光和机位，选择需要的资源；右侧面板调整选中对象或场景参数。
  2. 2
    检查构图自由视角用于观察和摆放场景；机位视角用于查看镜头构图。
  3. 3
    调整对象使用底部的移动、旋转、缩放工具调整所选对象。
  4. 4
    输出画面底部相机按钮截屏，录像按钮录制视角画面。

2D 画板：选好创作方式再生成

从画布左侧“画板”进入生成预览，点击“进入 2D 画板”绘制。画好后，选模型、填写描述，点“应用草图并生成”；也可直接在预览中选择模型、风格和生成方式。

参考草图Qwen-Image-Edit-2511、Codex 图像工具·参考编辑会读取当前绘画。这两项支持手动与实时模式；实时模式可按绘画变化继续生成，也可暂停。
文字创作Z-Image-Turbo、FLUX.1 [dev]、FLUX.2 [klein] 9B／4B、Codex 图像工具·生成仅用于手动模式。它们只读取描述与所选风格，不会读取草图；需要先填写画面描述。

手动模式共 7 个模型选项，实时模式共 2 个。画板每次生成一张；结果可在历史中回看、作为新参考继续编辑，也可下载、保存到资产或加入画布。

切入实时模式后，当前画面可能立即开始生成。整理或替换参考前先暂停；已提交的任务仍会在后台处理。
