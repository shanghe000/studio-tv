04

剪辑与导出

从画布左侧“剪辑”进入。当前图片、视频导入与预览有限支持：导入后素材可能不显示。需要稳定处理成片时，先从画布下载到本地剪辑软件。下图用于说明界面位置。

{{figure:overview-editor}}
  1. 1
    打开素材与文字左上可查看导入、画布素材、历史记录、我的资产和音效入口；文字可先从“文本”添加到时间轴。
  2. 2
    编排文字片段把文字拖入下方时间轴，调整位置和时长；选中片段后，在右侧编辑中文内容与样式。
  3. 3
    调整画幅与设置在播放器下方调整画幅比例；选中元素可查看属性，也可打开项目设置。使用图片或视频前，先确认素材能正常加载。
  4. 4
    查看导出选项右上“导出”可查看格式与参数。当前视频导入受限，稳定成片请在本地剪辑软件中导出；左上关闭按钮返回画布。
