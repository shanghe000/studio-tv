# 生成前提示布局修正（2026-11-03）

状态：IMPLEMENTED。发布结果以 main 流水线及 deployment-host 运行版本为准。

## 原因

上版将多行错误信息插入原生 `generate-btn-container`。冻结 CSS 对生成胶囊固定 36px、对 compact 操作行固定 52px，部分祖先还设置 `overflow:hidden` 和 `contain:layout style`；分组工具栏也固定高度。只增加 `flex-wrap` 无法改变这些约束，会造成重叠或裁切。

上次浏览器夹具缺少真实祖先类及完整冻结 CSS，仅模拟自然高度的按钮区域，未覆盖这一布局组合。本次保持冻结资源不变，在自有 TypeScript 中修正挂载方式。

## 新布局

- 提示直接挂载到 body 的独立区域，不向原生按钮、价格胶囊或操作行添加子元素，不修改其布局类。
- 保留每个按钮独立的参数检查，只显示当前相关的一处提示。隐藏、零面积和隐藏祖先下的控件不参与候选。
- 优先定位在完整参数面板、分组工具栏或失败覆盖层外；视口空间不足时自动收起为问题数量条。用户主动展开后才在可用空间展示详情，始终避开生成操作行。
- 文字换行、列表滚动、定位节点、收起/展开及 Escape 均独立工作，不触发原生生成回调。Escape 只在提示内部生效。
- 层级 2060 位于原生 modal 2000 / group toolbar 2050 之上、选择菜单 2100 之下。提示读取锚点主题变量，并跟随其移动，项目切换或销毁时清理。
- 模型/参数校验及服务端权限、版本、占用和一致性规则保持不变。

## 验收

浏览器夹具加载未修改的 `index-CP3PuX0B.css`，使用冻结 JSX 对应的图片、视频、文字、音频、展开 modal、分组和失败重试祖先结构；视频窄屏还加载已有 `installVideoComposerViewport`。数据为隔离的布局示例，不调用模型或修改生产项目。

- 七类入口的原操作尺寸保持不变；普通生成胶囊仍为 36px，提示为 body portal。
- 390×844 下八项长中文问题没有页面横向溢出，列表可滚动；收起后仅保留数量条。
- 定位点击在禁用胶囊外可用，生成回调为 0；修正可见输入后提示消失，点击仅回放一次原生生成回调。
- 原生选择菜单层级高于提示；展开面板空间不足时自动收起，Escape 收起后焦点回到展开按钮。
- 550×400 的缩小可用区域及锚点移动单独验证；几何测试覆盖顶部、底部、左右边缘、展开面板、长内容与窄屏。
- 使用指南及其截图随同更新；完整前端、构建、契约和发布检查由本次流水线记录。
